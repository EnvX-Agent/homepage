# EnvX

**An Agentic App Store for Open Source.**

EnvX turns any GitHub repository into a live, on-demand Repo-Agent — one click to discover, understand, set up, run, and integrate open-source AI projects with near-zero friction.

---

## What it does

- **Discover** — semantic search and compatibility scoring across open-source repos
- **Understand** — auto-generated knowledge cards and interactive Q&A for any project
- **Run** — one-click environment setup: dependencies, weights, data, validation
- **Extend** — context-aware code edits and natural-language coding helpers
- **Integrate** — expose repo capabilities as Agent-to-Agent (A2A) callable skills
- **Ship** — generate UIs, APIs, and shareable app cards from any repo
