# EnvX

**An Agentic App Store for Open Source.**

> One-Click to **Discover, Learn, Run & Remix** Any Open-Source Repo (AI App / Agent / Model / …)

EnvX is an Agentic App Store for Open Source — making useful, interesting, and trending repositories one-click usable, deployable, and composable.

We use AI Agents to bridge the full chain of **discovery → understanding → execution → reuse**, turning open-source projects into directly runnable Apps / Services / Agents.

Instead of just reading code, you can now **Discover, Learn, Run & Remix** any repo effortlessly. EnvX empowers everyone to access, build on, and benefit from the global open-source ecosystem — making AI open-source truly accessible and universal.

## Repo Agent System

EnvX combines specialized agents to turn repos into callable, composable capabilities — search, knowledge extraction, one-click setup, runtime orchestration, code assist, and A2A integration.

| Agent | Description |
|---|---|
| **Search & Index** | Semantic repo search and compatibility scoring. |
| **Repo Q&A / Wiki** | Auto-generated knowledge cards and interactive Q&A for each project. |
| **Setup & Run** | One-click environment assembly: deps, weights, data, validation. |
| **Vibe Coding** | Context-aware code edits and NL2Code helpers inside projects. |
| **A2A** | Expose repo capabilities as Agent-to-Agent callable skills. |
| **Repo2App** | Generate UIs, APIs, and shareable app cards from repos. |

## FAQ

**Why pay for open source?**
You're not paying for the code — it remains open and credited. You pay for compute, automation, reliability, and support that make repos usable as Apps.

**Can open-source authors participate?**
Yes. Authors can add the EnvX badge, receive sponsorship/shares, and use our tooling to package repos as App cards. We also contribute back via PRs and issue fixes.
